# makebody (FORM 운동 라이브러리)

## 1. 프로젝트 소개

한국어 운동 라이브러리 겸 운동 기록 웹앱입니다. 부위와 보유 기구에 맞는 운동을 찾고, 사용 근육이 강조된 동작 애니메이션으로 자세를 확인한 뒤, 세트·횟수·무게를 기록하는 것이 목적입니다. 서버나 API 키 없이 브라우저만으로 동작합니다.

## 2. 기술 스택

- **프론트엔드:** React 19, TypeScript, Vite
- **아이콘:** lucide-react
- **데이터 저장:** 브라우저 localStorage
- **배포:** GitHub Pages (GitHub Actions 자동 빌드·배포)

## 3. 이용 방법

**웹사이트:** https://imjw0826.github.io/makebody/

- 근육 부위를 고르거나 한국어/영어 이름으로 운동을 검색합니다.
- 가지고 있는 기구를 선택하고 **내 기구로만 보기**를 켜면 할 수 있는 운동만 보입니다.
- 운동을 선택하면 동작 애니메이션(재생·일시정지, 0.5×–2× 속도, GIF 저장), 방법, 팁, 필요 기구, 난이도를 볼 수 있습니다.
- 별 버튼으로 즐겨찾기를 저장하고, 세트·반복 횟수·무게·날짜를 입력해 운동 기록을 남깁니다.
- 기록과 즐겨찾기는 현재 브라우저에만 저장되며 기기 간 동기화는 되지 않습니다.

로컬에서 실행하려면 Node.js 22 이상이 필요합니다.

```sh
git clone https://github.com/imjw0826/makebody.git
cd makebody
npm install
npm run dev
```
